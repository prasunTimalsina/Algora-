## �🌟 Features

### 🎯 Core Functionality

- **Problem Solving**: Browse and solve coding problems with varying difficulty levels (Easy, Medium, Hard)
- **Real-time Code Execution**: Execute code in multiple programming languages with instant feedback
- **Comprehensive Testing**: Automated test case validation with detailed results
- **Performance Analytics**: Track runtime, memory usage, and performance percentiles
- **Submission History**: View all your previous submissions with detailed metrics

### 👤 User Management

- **Authentication**: Secure user registration and login system
- **OAuth Integration**: Login with Google and GitHub using Arctic OAuth
- **Profile Management**: Personalized user profiles with avatars
- **Progress Tracking**: Detailed statistics and progress analytics

### 📊 Analytics & Insights

- **User Statistics**: Track solved problems, submission rates, and success percentages
- **Streak Tracking**: Monitor daily coding streaks and longest streaks
- **Performance Metrics**: Analyze runtime and memory consumption patterns
- **Daily Activity**: Track daily problem-solving activity

### 🎵 Organization Features

- **Problem Playlists**: Create and manage custom problem collections
- **Tagging System**: Organize problems with custom tags
- **Difficulty Filtering**: Filter problems by difficulty levels
- **Search & Discovery**: Find problems efficiently

### 💻 Developer Experience

- **Monaco Editor**: Advanced code editor with syntax highlighting and IntelliSense
- **Multi-language Support**: Write solutions in various programming languages (only javascript, python , java are included for now)
- **Responsive Design**: Optimized for desktop and mobile devices
- **Dark/Light Theme**: Toggle between themes for comfortable coding

- Node.js (v18 or higher)
- PostgreSQL database
- Judge0 API access (for code execution)

### 🔧 Installation

1. **📥 Clone the repository**

   ```bash
   git clone https://github.com/prasunTimalsina/Algora-.git
   cd Algora
   ```

2. **🔙 Install Backend Dependencies**

   ```bash
   cd backend
   npm install
   ```

3. **🎨 Install Frontend Dependencies**

   ```bash
   cd ../frontend
   npm install
   ```

4. **⚙️ Environment Setup**

   Create `.env` file in the backend directory:

   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/Algora"
   JWT_SECRET="your-jwt-secret"
   JWT_REFRESH_SECRET="your-jwt-refresh-secret"

   # OAuth Credentials
   GOOGLE_CLIENT_ID="your-google-client-id"
   GOOGLE_CLIENT_SECRET="your-google-client-secret"
   GITHUB_CLIENT_ID="your-github-client-id"
   GITHUB_CLIENT_SECRET="your-github-client-secret"

   # Judge0 Configuration
   JUDGE0_API_URL="your-judge0-api-url"
   JUDGE0_API_KEY="your-judge0-api-key"

   # Email Configuration
   EMAIL_HOST="your-email-host"
   EMAIL_PORT=587
   EMAIL_USER="your-email"
   EMAIL_PASS="your-email-password"
   ```

5. **🗄️ Database Setup**

   ```bash
   cd backend
   npx prisma migrate dev
   npx prisma generate
   ```

6. **🚀 Start Development Servers**

   **Backend:**

   ```bash
   cd backend
   npm run dev
   ```

   **Frontend:**

   ```bash
   cd frontend
   npm run dev
   ```

## 🔌 API Endpoints

### Authentication

- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User login
- `POST /api/auth/refresh` - Refresh access token
- `POST /api/auth/logout` - User logout

### Problems

- `GET /api/problems` - Get all problems
- `GET /api/problems/:id` - Get specific problem
- `POST /api/problems` - Create new problem (Admin)
- `PUT /api/problems/:id` - Update problem (Admin)
- `DELETE /api/problems/:id` - Delete problem (Admin)

### Submissions

- `POST /api/submissions` - Submit solution
- `GET /api/submissions/user/:userId` - Get user submissions
- `GET /api/submissions/problem/:problemId` - Get problem submissions

### Code Execution

- `POST /api/execute` - Execute code with test cases
- `GET /api/execute/status/:token` - Get execution status

### Playlists

- `GET /api/playlists` - Get user playlists
- `POST /api/playlists` - Create playlist
- `PUT /api/playlists/:id` - Update playlist
- `DELETE /api/playlists/:id` - Delete playlist
